# Hactex — React Edition

An admin dashboard template built with **React 19 + TypeScript** on **Vite**, routed with **React Router** as a single-page app, styled with **Tailwind CSS v4** (Bold Press design language).

## Requirements

- Node.js 20.19+ or 22.12+ (includes npm) — the floor is Vite 6's

## Getting started

From this folder (`template/`):

1. **Install dependencies**

   ```bash
   npm install
   ```

2. **Start the dev server** (hot reload on http://localhost:5181)

   ```bash
   npm run dev
   ```

3. **Create a production build** (outputs to `dist/`)

   ```bash
   npm run build
   ```

4. **Preview the production build locally**

   ```bash
   npm run preview
   ```

## Where you land

The entry route redirects to `/dashboards`. If the first thing you see is the Sales dashboard, everything is wired correctly.
